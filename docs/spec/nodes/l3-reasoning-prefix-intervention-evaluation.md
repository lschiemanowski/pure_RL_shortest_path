# Reasoning-prefix intervention evaluation

A reasoning-prefix intervention study measures when an ordinarily generated reasoning trace first supports a successful answer. It begins with one unmodified completion for every problem in a declared independent evaluation set. For each baseline completion whose reasoning segment parses, the study selects every prefix that satisfies the policy's minimum reasoning length and ends in a node token. A restart marker alone is not an eligible boundary.

At each eligible boundary, the study retains the baseline reasoning prefix, appends the reasoning terminator and answer-begin marker, and then generates an unconstrained suffix under the study's declared greedy sampling configuration. The reconstructed completion is verified under the same task semantics as ordinary evaluation. The policy remains in evaluation mode, receives no parameter update, and is loaded without an optimizer, reference policy, or curriculum state.

Every intervention remains paired with its ordinary baseline. The study records the checkpoint path and file digest, embedded run and step identities, resolved study configuration, source state, problem-set identity, ordered problem index, retained prefix and boundary position, forced markers, generated suffix, termination condition, and deterministic verifier outcome. Baselines without an eligible boundary remain explicit. Results summarize ordinary and intervened outcomes separately and never present prefix interventions as unmodified policy performance. Each invocation writes a new artifact directory and refuses to overwrite existing evidence.
