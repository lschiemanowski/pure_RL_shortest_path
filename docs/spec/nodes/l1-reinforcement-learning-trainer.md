# Reinforcement-learning trainer

The reinforcement-learning trainer improves the transformer policy solely from
experience generated by the policy on training problems supplied by the
surrounding experiment. Demonstrated solutions, teacher reasoning, and
supervised target completions do not enter this process.

Rollout sampling produces declared groups of completions from the current policy without task-specific token constraints and retains the rollout-time statistics required by the selected optimizer.

Reward computation converts verifier facts into a scalar reward and keeps
optional reward shaping and auxiliary objectives explicit and separately
configurable.

A run selects either the existing group-relative update or PPO-Clip with a learned value function and generalized advantage estimation. Both operate only on sampled policy actions and keep divergence and auxiliary losses explicit. The trainer does not select the task distribution, evaluate checkpoints, or decide curriculum advancement.
